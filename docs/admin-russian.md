# Русский интерфейс Django Admin

Административная панель доступна по адресу `/admin/`. Язык интерфейса — русский.

Переведены названия предметных приложений:

- «Пользователи»;
- «Каталог цветов»;
- «Конструктор букетов».

На русский переведены названия моделей и полей пользователей, ролей, профилей, адресов,
окружения, справочников цветов, зелени, упаковки и пользовательских букетов. Стандартные
кнопки, фильтры, сообщения, формы входа и системные модели переводит локаль Django `ru-ru`.

Названия таблиц и полей PostgreSQL не менялись. Миграции изменяют метаданные Django,
которые используются в административном интерфейсе:

- `accounts/0004_alter_customeraddress_options_and_more.py`;
- `catalog/0002_alter_flowercolor_options_alter_flowertype_options_and_more.py`;
- `bouquet_builder/0002_alter_custombouquet_options_and_more.py`.
